# INVTI website (Privacy Policy & Terms)

Static site for GitHub Pages. Korean / English switch in the header.

| Page | File | Address |
| --- | --- | --- |
| Home | `index.html` | `/` |
| Privacy Policy | `privacy/index.html` | `/privacy/` |
| Terms of Service | `terms/index.html` | `/terms/` |
| Not found | `404.html` | any wrong address |

Add `?lang=en` or `?lang=ko` to a link to open it in that language
(e.g. `.../privacy/?lang=en`).

## Publish
1. Create a new public repository (e.g. `invti`).
2. Upload everything in this folder to the repository root.
3. Settings → Pages → Source: "Deploy from a branch" → `main` / `/ (root)` → Save.
4. After about a minute the site is live at `https://<your-username>.github.io/invti/`.
   Privacy Policy URL for the store: `https://<your-username>.github.io/invti/privacy/`
